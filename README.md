# على الباب — دليل التشغيل

لعبة تدريب على العزل ونظافة الإيدين: **مبارزة** باللينك، و**العب لوحدك**، و**طلّع الغلطات**، وصفحة **رئيس القسم** (نتايج + إضافة أسئلة).

React (Vite + TypeScript) + Supabase. الرفع على Vercel.

---

## ١) إعداد Supabase (مرة واحدة)

### أ. قاعدة البيانات
1. افتح مشروعك في Supabase ← **SQL Editor** ← **New query**.
2. الزق محتوى `supabase/schema.sql` كله واضغط **Run**.
3. New query تاني، الزق `supabase/seed.sql` واضغط **Run**. ده بيضيف الأقسام والـ 14 سؤال الأساسيين.
4. لو كنت شغّلت نسخة قديمة من `schema.sql` قبل كده، شغّل ملفات الإصلاح اللي مشغلتهاش بالترتيب: `fix_01` ← `fix_02` ← `fix_03` ← `fix_04` ← `fix_05` (كلهم في فولدر `supabase`). لو بتبدأ من الأول، `schema.sql` + `seed.sql` كفاية.
5. لو مشروعك قديم (شغّلت schema.sql قبل كده)، شغّل بالترتيب: `fix_01_profile.sql` ← `fix_02_spot_scenes.sql` ← `fix_03_spot_random.sql`. لو لسه بتعمل المشروع من الأول، `schema.sql` + `seed.sql` كفاية.

### ب. فعّل الدخول من غير حساب للاعبين
**Authentication ← Sign In / Providers ← Anonymous sign-ins ← فعّلها ← Save.**

> مهم: Supabase بيسمح افتراضيًا بـ **30 دخول من غير حساب في الساعة من نفس الـ IP**. لو كل الموبايلات في المستشفى على نفس الواي فاي، هيقفوا عند 30 لاعب جديد في الساعة.
> زوّده من **Authentication ← Rate Limits ← Anonymous users** (مثلًا 300).

### ج. اعمل حسابات رؤساء الأقسام
1. **Authentication ← Users ← Add user ← Create new user**: اكتب الإيميل والباسورد، وعلّم على **Auto Confirm User**.
2. بعدها من **SQL Editor** شغّل سطر لكل واحد:

```sql
-- رئيس قسم (بيشوف قسمه بس، ويضيف أسئلة ويعدّل أسئلته هو بس)
insert into public.managers (user_id, display_name, dept_id)
select id, 'د. منى', (select id from public.departments where name = 'الرعاية المركزة')
from auth.users where email = 'mona@example.com';

-- أدمن (بيشوف كل الأقسام، ويعدّل أو يوقف أي سؤال) — مثلًا دكتورة مكافحة العدوى
insert into public.managers (user_id, display_name, is_admin)
select id, 'وحدة مكافحة العدوى', true
from auth.users where email = 'ipc@example.com';
```

### د. لو عايز تضيف أو تغيّر الأقسام
```sql
insert into public.departments (name, sort) values ('الكلى', 7);
```

### هـ. المفاتيح
من **Project Settings ← API** خد:
- **Project URL**
- **anon public key**

**ممنوع تحط الـ `service_role` key في الكود أو تبعتها لحد.**

---

## ٢) التشغيل على جهازك

```bash
npm install
cp .env.example .env.local     # وحط فيه الـ URL والـ anon key
npm run dev
```
افتح اللينك اللي هيظهر (غالبًا http://localhost:5173).

---

## ٣) الرفع على Vercel

1. ارفع الفولدر ده على ريبو GitHub (من غير `node_modules` و `.env.local`).
2. في Vercel: **Add New ← Project ← Import** الريبو.
3. في **Environment Variables** ضيف:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. **Deploy**. ملف `vercel.json` موجود عشان اللينكات زي `/g/ABC123` تشتغل.

## إزاي الحاجات شغالة

| الحاجة | الطريقة |
|---|---|
| اللاعب | بيدخل اسمه وقسمه مرة واحدة. Supabase بيديله رقم مميز للجهاز ده (Anonymous Auth). |
| المبارزة | اللاعب الأول بيعمل مبارزة وياخد لينك `/g/CODE`. زميله يفتحه من موبايله ويلعب نفس الحالات بنفس الترتيب. النتيجة بتظهر للاتنين لما الاتنين يخلّصوا (الصفحة بتتحدّث لوحدها كل 6 ثواني). |
| الدرجة | بتتحسب **على السيرفر** (`answer_door`). الإجابات الصح في جدول `case_answers` محدش يقدر يقراه. الإجابة الصح بتظهر للاعب بس بعد ما يجاوب. |
| الوقت | بداية كل باب بتتسجل على السيرفر. لو اللاعب عمل ريفريش الوقت مبيرجعش من الأول. |
| رئيس القسم | بيدخل بإيميل وباسورد. بيشوف قسمه بس، والأدمن بيشوف الكل. |
| الأسئلة | رئيس القسم بيضيف سؤال ويتنزل على طول. يقدر يعدّل أو يوقف أسئلته هو بس. الأدمن يقدر يعدّل أو يوقف أي سؤال. |
| المشاركة | زرار المشاركة بيفتح قايمة المشاركة بتاعة الموبايل، ولو مش متاحة بيظهر واتساب ونسخ اللينك. |

## حدود لازم تعرفها
- **الاسم مش متأكد منه:** أي حد يقدر يكتب أي اسم. لو النتايج هتدخل في تقييم رسمي، محتاجين تسجيل دخول حقيقي (رقم وظيفي مثلًا).
- **لو اللاعب مسح بيانات المتصفح أو غيّر الموبايل**، بيتعامل كلاعب جديد.
- **درجة "طلّع الغلطات" بتتحسب على الموبايل** (أهميتها أقل، ومتحددة بحد أقصى في قاعدة البيانات).
- **صور "طلّع الغلطات" ثابتة في الكود** (`src/art.ts` ← `spotSVG` و `DIFFS`).
- **أسماء الموظفين ونتايجهم بيانات شخصية:** خدوا موافقة المستشفى.

## الملفات المهمة
```
supabase/schema.sql      الجداول + الحماية (RLS) + كل الفنكشنز
supabase/seed.sql        الأقسام + الأسئلة الأساسية
src/screens/             شاشات اللاعب (Home, Game, DoorGame, Spot ...)
src/manager/             صفحة رئيس القسم + محرر الأسئلة
src/art.ts               الرسومات (الأوضة، الشخصية، صورة الغلطات)
src/lib/content.ts       أسماء اللافتات والواقيات ورسايل الأخطاء
```
